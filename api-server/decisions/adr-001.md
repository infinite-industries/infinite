Online Resource Representation
===============================

Online Resources are resources that do not have start/end times or locations. They are intended to represent things
like links to permanent resources, such as free cultural streaming services, libraries, or other pages that offer
rich information about the community. This was implemented quickly during the pandemic. To allow for quick implementation
we leveraged the existing events data model. Online resources exist as events:

* With the category set to online-resource
* No venue
* No date/times

Note: The main distinguishing parameter is the category, set to online-resource. There examples in the DB where they
have venues or date/times. This is not necessarily how they should have been entered, but it doesn't hurt anything.

* Fetching: Use the events/verified endpoint, passing category=`category=online-resource` to fetch Online Resources.
  `curl 'http://localhost:3003/v1/events/verified?category=online-resource'`
* Online Resources are not included in /current-events results. They are not current events because they do not exist
  in time

## Looking Forward

* These should eventually have their own data model and table in the database.
* They should have their own set of endpoints in the API for data access and mutation
